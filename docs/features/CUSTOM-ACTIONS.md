# Custom actions

Custom actions (user-defined commands in the file-view context menu, configured
through an `actions.json` file) are **not implemented**. Mariner reads no
`actions.json` and has no setting for user-defined menu entries. The README
lists the feature under "Not yet supported".

This page is a placeholder so links do not break. It will be replaced with a
real guide when the feature lands.

## What you can do today

- **Command runner:** type `!` in the location bar (**Ctrl+L**) to run a shell
  command in the current folder, with output in a bottom panel. `!!command` runs
  it in your terminal app.
- **Command palette:** **Ctrl+P** runs any built-in action.
- **Open with:** the context menu can open files with other applications.
